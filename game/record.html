Recording studio

How it works
  1. Pick a language. Read each phrase aloud in a bright, happy, young voice, close to the microphone, in a quiet room.
  2. Tap Record, say the phrase, tap Stop. Silence at the start and end is trimmed automatically. Re-record any clip you don't like.
  3. Clips stay in this browser (nothing is uploaded). Come back any time to carry on.
  4. Tap Download zip. Unzip it inside the game folder so the files land in game/audio/voice/, then tell Claude to publish them.
Start with Essentials: the reactions, letters, numbers to 30 and the family names. A sentence only uses your voice when every piece in it is recorded, so the picture words and big numbers come second.
